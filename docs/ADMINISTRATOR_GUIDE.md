# Administrator Guide

The first account is the permanent Super Owner and bypasses all application permission checks. Do not share it for daily work. Create named users with the least role and branch access required; deactivate departed users rather than reusing accounts.

Administrators own Settings, users/roles, branches, hardware, WhatsApp, licensing UI, database diagnostics, backup/recovery, imports/exports, financial period controls, and Hybrid configuration. Review audit logs, unresolved sync conflicts, failed communication queue items, backup age, and license state daily during the test release.

Never send passwords, Wasender credentials, service-role keys, or backups over untrusted chat/email. The Hybrid service-role key is setup-only and must be rotated if exposure is suspected.
