# Setup Guide

1. Choose Offline (recommended) or owner-configured Hybrid.
2. Create the first account. It becomes the permanent Super Owner.
3. Configure firm identity, branch, document numbering, gold/purity defaults, fiscal/GST behavior, and backup location in Settings.
4. Configure printers/scanner only if present; run a non-financial sample preview.
5. Configure WhatsApp only if online messaging is required.
6. Create restricted users/roles and verify branch scope.
7. Record opening gold exclusively through approved Gold Vault workflows.
8. Create and restore a backup before entering live workshop data.

Offline setup requires Full Name, Email, Password, Confirm Password, and an Arivahly-issued License Key. Hybrid first validates the same central license, then requires the owner-applied master SQL plus Project URL, anon key, and a temporary service-role key. See [Hybrid Mode Guide](HYBRID_SETUP.md).
