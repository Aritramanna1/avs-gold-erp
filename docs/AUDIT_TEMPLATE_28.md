# 28-Point Print Preview Standardized Audit Template

This standard reference document outlines the systematic audit verification checklist for all **28 printed documents** generated by the **Areva Venture Studios ERP System**. Use this script during physical testing or client audits to confirm visual fidelity, company branding, scan safety, and calculation integrity.

---

## 1. Audit Guidelines & Passing Criteria

Each document printed or previewed must satisfy the **Six core checkpoints** to be marked **PASS**:

| ID     | Check Category             | Passing Criteria                                                                                                                  | Status              |
| ------ | -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| **C1** | **Dynamic Shop Profile**   | Shows dynamic shop name, tagline, address, and logo matching settings (no "Maa Tara Jewellers" hardcoded defaults unless seeded). | [ ] PASS / [ ] FAIL |
| **C2** | **Secure QR Code**         | High-contrast QR code present, matches the document schema, resolves to the correct hash verification signature.                  | [ ] PASS / [ ] FAIL |
| **C3** | **No Visual Slop**         | Zero placeholders, no `NaN`, `undefined`, `null`, `[object Object]` or blank fields showing in labels or rows.                    | [ ] PASS / [ ] FAIL |
| **C4** | **Standard AVS Footer**    | "Made with Areva Venture Studios ERP System" small credit line visible in positive/negative layouts.                              | [ ] PASS / [ ] FAIL |
| **C5** | **Offline/Dialog Control** | "Reprint Indicator" and "Print Dialog trigger" buttons function on screen; hide fully during browser printing (`@media print`).   | [ ] PASS / [ ] FAIL |
| **C6** | **Signature Lines**        | Proper spacing at the bottom with labels like "Customer Signature" and "For [Shop Name]" or customized sign-offs.                 | [ ] PASS / [ ] FAIL |

## 2. 28-Point Document Registry & Test Configurations

Execute this script across all 28 paths using a test record or the mock database state.

### Category A: Customer Orders & Receipts (Document 1–7)

_Tested in Section: Orders Panel & Ingestion_

```markdown
1. ORDER SLIP
   - Route: `/orders/print/slip/:id`
   - Test record: Custom Order (e.g. "Kolkata Filigree Ring")
   - Expected: Item particulars, estimated weight, expected delivery date, QR code, dynamic signature line.

2. CUSTOMER GOLD RECEIPT
   - Route: `/orders/print/customer-gold/:id`
   - Test record: Pure Gold Advance on Order
   - Expected: Item details, customer gold weight, purity per-mille, target application status.

3. OLD GOLD RECEIPT
   - Route: `/orders/print/old-gold/:id`
   - Test record: Scrap Gold taken in advance
   - Expected: Old gold details, purity estimate, deduction notes, QR verification.

4. CASH ADVANCE RECEIPT
   - Route: `/orders/print/advance/:id`
   - Test record: Rupees Advance on Order (cash/UPI)
   - Expected: Advanced amount, mode of payment, pending order No, date stamp.

5. ADVANCE SETTLEMENT RECEIPT
   - Route: `/orders/print/settlement/:id`
   - Test record: Order finished with ledger write-off
   - Expected: Combined cash/gold settlements displayed under a clean table layout.

6. FINAL INVOICE SLIP
   - Route: `/orders/print/invoice/:id`
   - Test record: Draft Order converted to billing Invoice
   - Expected: Shop logo, tax invoice numbering, SGST/CGST breakdown, net payable.

7. LABELS & METALLIC TAG (DUAL COPY)
   - Route: `/orders/print/tag/:id`
   - Test record: Catalog Item Label
   - Expected: Barcode/QR, gross weight, HUID, price (if visible in hardware preferences).
```
