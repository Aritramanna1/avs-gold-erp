# Coding Standards

## TypeScript

- Strict mode. **No new `any`** at boundaries — model domain types (`LedgerEntry`, `PrintDocumentData`, …).
- String-union enums, not TS `enum`.
- Validate at trust boundaries (form input, IPC payloads, Supabase reads).
- Prefer pure functions for domain math; keep side effects in store methods.

## Reuse before writing (the first rule)

Before adding anything, look for an existing helper/service/component/type/pattern and reuse it. The most common defect is re-implementing what already lives a few files over. Specifically:

- Persistence → `createRepository`, `local-db`, `sync-engine`, `supabase-write`. Never ad hoc remote writes.
- Print → Universal Print Engine. Export → `report-engine.ts`. WhatsApp → `send-whatsapp-text`/`send-whatsapp-document`.
- Gold math → `gold.ts` (`fineGoldMg`, `mgToGrams`, `getCaratLabel`). Money → `paiseToRupees`.
- Numbering → `nextDocumentNumber`.

## Routes stay thin

Routes wire and present. Domain behavior lives in `src/lib` services/stores. No business math in a `.tsx` route beyond trivial display formatting.

## Accounting

Integer mg / per-mille / paise everywhere. Bucket deltas must reconcile to `netFineMg`. Balances derive from movement logs.

## Tests / verification

- Non-trivial logic (a parser, a money path, a running-balance) leaves **one runnable check** — an `assert`-based `*.selfcheck.ts` run via `npx tsx`. Example: `daily-material-slip.selfcheck.ts`.
- **Never run Playwright.** Manual verification happens in the Electron app.
- After any implementation, run `tsc --noEmit`, `vite build`, and ESLint; fix failures before finishing; then launch Electron.

## Generated files

Never hand-edit `src/routeTree.gen.ts` — it is regenerated by the router plugin on dev/build.

## Comments

Match surrounding density. Explain *why*, not *what*. Mark deliberate simplifications with a `ponytail:` comment naming the ceiling and upgrade path.

## Formatting

Prettier + ESLint enforced. Run `eslint --fix` on touched files. CRLF↔LF warnings from git are expected on Windows and harmless.
