# Ornexa Workflow Catalog

## Customer Order To Cash

Inquiry/quotation -> order -> approval -> plan/allocate -> manufacture -> QC/approval -> tag/stock -> invoice -> payment/credit -> dispatch -> close.

## Purchase And Inward

Supplier -> purchase/PO -> receipt/verification -> weigh/assay -> QC -> stock/tag -> supplier invoice -> payable -> payment/return.

## Manufacturing Issue Receive

Demand -> material reservation -> process/worker issue -> print issue note -> WIP accountability -> partial/final receive -> loss/waste/recovery -> QC -> next process/finished stock/rework/scrap.

## Job Worker / Karigar

Karigar master -> skill/rate setup -> assigned jobs -> metal/stone issue -> partial return -> finished return -> scrap/dust/recovery -> labour -> outstanding -> settlement -> passbook/portal.

## Old Gold

Customer old gold -> appraisal -> gross/purity/touch -> deduction/melting loss -> fine weight -> valuation -> customer credit/settlement -> old gold inventory -> refinery if needed.

## Hallmark

Finished jewellery -> hallmark outward -> custody -> pending -> return -> weight difference -> HUID -> pass/reject -> stock.

## Branch Transfer

Source branch -> transfer dispatch -> in transit -> destination receipt -> reconciliation -> variance approval.

## Payment And Settlement

Invoice/worker/supplier/payroll balance -> allocation -> cash/bank/credit/rate-cut posting -> receipt -> remaining balance or visible unallocated credit.
