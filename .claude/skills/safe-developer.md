Before writing any code:

1. Read only the files required.
2. Never assume file contents.
3. If uncertain, inspect the file.
4. Preserve existing functionality.
5. Prefer modifying existing code instead of rewriting.
6. Explain your plan before coding.
7. Make the smallest possible change.
8. Run tests after changes.
9. Fix any failing tests before finishing.
10. Never delete code unless explicitly instructed.
11. If requirements are ambiguous, ask.
12. Review the final diff.
13. Check formatting.
14. Check TypeScript errors.
15. Check build errors.
16. Check lint.
17. Produce a summary of changes.
