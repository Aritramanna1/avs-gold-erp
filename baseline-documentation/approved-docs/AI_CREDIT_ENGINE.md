# ORNEXA — UNIFIED CREDIT ENGINE MASTER
**Commercial Usage, Wallet & Metering Architecture for Variable-Cost Platform Services**
*Version: 4.0.0*

---

## 1. Core Principles

1. **Unified Platform Currency:** A single commercial unit ("Ornexa Credits") meters all variable-cost cloud services:
   - Cloud AI (Token Reasoning)
   - WhatsApp Business API (Marketing, Utility & Service conversations)
   - Premium Multimodal Vision / OCR
2. **Append-Only Credit Ledger:** Balance updates are derived strictly from immutable credit transaction records.
3. **Graceful Degradation:** When credits run out, the ERP and Assistant **never break**. The system gracefully falls back to zero-cost local intelligence and standard workflows.
