# Ornexa Roles Permissions Matrix

## Reference Roles

Software Owner, Tenant Owner, Super Admin, Admin, CEO, Branch Manager, Sales Manager, Sales Executive, Inventory Manager, Purchase Manager, Production Manager, Accounts/Accountant, Billing, QC Manager, Vault, Workshop, Karigar/Production User, Viewer.

## Permission Verbs

View, create, edit, post, submit, approve, reject, reverse, delete draft, export, print, share, transfer, adjust, configure, manage users, view cost, view metal balance, view financial balance, use AI actions.

## Rule

Roles are not navigation presets. Permissions must control actions and sensitive data access server-side/RLS, not only menu visibility.
