# Administrator Guide

The first platform/firm owner account is highly privileged. Do not share it for daily work. Create named users with the least role and branch access required; deactivate departed users rather than reusing accounts.

Administrators own Settings, users/roles, branches, hardware, WhatsApp, licensing UI, database diagnostics, Supabase backup/recovery, imports/exports, financial period controls, and operational monitoring. Review audit logs, failed communication items, backup age, RLS/security warnings, unresolved support tickets, and license state daily during the test release.

Never send passwords, Wasender credentials, access tokens, service-role keys, SQL connection strings, or backups over untrusted chat/email. Production recovery and configuration changes must use approved Supabase-controlled workflows; retired Offline/Hybrid setup keys must not be reintroduced.
